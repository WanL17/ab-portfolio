My Projects

Here are some of my projects:

🤖 Corewar

The goal of this project is to make a battle royale among robots. We had to create a virtual machine and manage its memory, compile the robot files and execute their commands.

💻 42sh

In a group of 5 people we managed to make a functional shell inspired by TCSH entirely in C.

🎮 Wolf3D

This project is a video game we made with two other classmates. It's a First Person Shooter inspired by Wolfenstein3D powered by an optimized raycast entirely made in C thanks to the CSFML library. It features multiple menus, enemies, musics, increased difficulty and also controller support. We decided to mix the style of the original Wolfenstein3D game with the style of Persona 5 and this is the result.

🐍 Csnake

To test my knowledge and my skills about C, I decided to remake the famous game Snake for terminal user interface thanks to the Ncurses library.

📄 Cuddle

This is the first project of data of the 1st year at EPITECH. This project is a remake of the Pandas library in C, which consists on get, then parse and sort informations from a CSV file.
